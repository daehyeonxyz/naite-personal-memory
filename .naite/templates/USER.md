# USER.md — 사용자 모델 (응답 선호 표면)

이 파일은 에이전트가 "이 사용자를 어떻게 대해야 하는가" 를 담는 시스템 표면이다. 세션마다 읽힌다.

> **이것은 템플릿이다.** 실제 값은 vault 루트의 `USER.md` 에 채운다. 루트 `USER.md` 는 `.gitignore` 로 공개 repo 에 올라가지 않는다. 신원·이력 같은 깊은 개인 정보는 여기에 복제하지 말고 `tree/personal-profile.md` (`kind=personal`) 에 두고 `[[personal-profile]]` 로 가리킨다. PII(주소·전화·식별번호)는 이 파일에 적지 않는다.

작성 원칙은 간단하다. **추정으로 채우지 않고, 사용자가 동의한 정보만** 적는다.
