# MEMORY.md — 운영 메모리 (통합 표면)

이 파일은 진행 중인 작업과 프로젝트 운영 사실을 한곳에 모으는 통합 메모리 표면이다. 여기저기 흩어진 메모리를 관리하는 단일 인덱스 역할을 한다.

> **이것은 템플릿이다.** 실제 메모리는 vault 루트의 `MEMORY.md` 에 쌓는다. 루트 `MEMORY.md` 는 `.gitignore` 로 공개 repo 에 올라가지 않는다.

---

## 규율 (memory discipline)

- 메모리는 **선언적 사실**로 적는다 (지시문이 아니라 상태).
- 한 항목은 한 사실로 적고, 출처와 날짜를 함께 단다. 상대 날짜는 절대 날짜로 바꿔 적는다.
- **일주일이 지나 더 이상 맞지 않으면 메모리에 있을 자격이 없다.** 낡으면 지운다.
- 큐레이션은 에이전트가 제안하고, 삭제와 통합은 사용자와 합의하거나 분명할 때만 한다 (naite `care` 철학과 같다).
- 나무(`tree/`)는 큐레이션된 장기 지식이고, 이 파일은 휘발적 운영 기억이다. 둘을 섞지 않는다. 오래 남길 지식은 `/naite grow` 로 나무에 새긴다.
