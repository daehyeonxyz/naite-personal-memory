# 메모리 이전 프롬프트

naite 를 처음 시작할 때, 빈 나무 대신 **이미 다른 AI 에 쌓아둔 내 기록**으로 첫 나무를 짓기 위한 프롬프트다. 아래 블록을 통째로 복사해 평소 쓰는 AI(ChatGPT / Gemini / Claude) 에 붙여넣고, 나온 결과(Markdown 한 덩어리)를 다시 `/naite start` 로 가져온다.

## 붙여넣을 프롬프트

`````text
너는 나와 나눈 대화와 너에게 저장된 메모리를 통틀어 나를 알고 있다. 그 앎에서 내가 다른 곳으로 가져가 오래 쓸 가치가 있는 것들을 빠짐없이 끌어내, 하나의 Markdown 문서로 정리해줘.

다음 6개 섹션으로 나눠서 적어줘:

1. 배운 것: 개념, 지식, 강의·책·논문·아티클에서 얻은 이해
2. 내린 결정과 trade-off: 무엇을 왜 선택했고 무엇을 보류·포기했는지, 실패와 그 이유 포함
3. 프로젝트: 했거나 하고 있는 일, 목표와 현재 상태
4. 반복되는 관심사·주제: 자주 돌아오는 분야
5. 미해결 질문: 아직 답을 못 찾은 것
6. 선호·작업 방식: 내가 일하고 생각하는 방식, 도구 취향

규칙:
- 포괄적으로, 기억나는 걸 빠뜨리지 말고 구체적으로 적어줘. 얕게 요약하지 마.
- 각 항목은 그 자체로 이해되는 독립된 문장으로 적어줘 (나중에 한 장의 노트로 떼어낼 수 있게).
- 비밀번호, API 키, 토큰, 전체 주소, 주민번호 같은 비밀이나 개인 식별정보는 절대 포함하지 마.
- 출처나 사실 여부가 불확실한 건 끝에 (추측) 이라고 표시해줘.
- 순수 Markdown 한 덩어리로만. 특정 앱의 태그나 메타데이터는 붙이지 마.

다 적었으면 내가 통째로 복사할 수 있게 한 블록으로 보여줘.
`````

## 서비스별 팁

- **ChatGPT:** 설정 > 개인 맞춤 설정 > 메모리가 켜져 있으면 그 메모리를 우선 활용하고, 최근 대화도 함께 훑으라고 한 줄 덧붙인다. 메모리가 꺼져 있으면 최근 대화 기반으로 진행한다.
- **Gemini:** 활동 기록과 저장된 정보를 활용하라고 덧붙인다.
- **Claude (claude.ai):** 프로젝트와 대화 기록을 활용하라고 덧붙인다. claude.ai 의 메모리 기능이 있으면 함께 쓴다.
- **결과가 빈약하면:** "기억나는 것을 직접 적어줘" 로 폴백한다. 적은 양이라도 첫 나무의 씨앗이 된다.
